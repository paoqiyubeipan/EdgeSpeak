# EdgeSpeak 安卓版

和电脑版同一套查词逻辑：假名注音、音高、原型和变形拆解、英文和中文释义（含网络用语标记）、点英文单词查中文、点到英文单词时直接查英汉词典、AI 结合上下文解释（Cohere / Mistral / OpenRouter，带备用模型），以及朗读。词典全部在手机里，不联网也能查；只有 AI 解释需要联网。

## 安装

把 `EdgeSpeak-Android-1.1.0.apk` 传到手机上打开安装（需要允许「安装未知应用」）。要求 Android 11 及以上。

第一次打开时会把词典解压到手机里（约 370 MB，几秒到十几秒）。

## 用法

1. **选字菜单**：在任何 App 里长按选中文字，弹出的菜单里点 **EdgeSpeak 查词** 或 **EdgeSpeak 朗读**（有的 App 要先点菜单里的 ⋮）。
   - 查词：在原来的 App 上面弹出卡片。上面是选中的整段文字，点里面的任意字就换成那个词；点标题朗读；点英文释义里的单词，下面显示它的中文意思。
   - 选中的（或点到的）是英文单词时，显示英文卡片：音标、中文释义、考试标签和变形，AI 结合句子解释它在这里的意思并翻译整句。选中整段英文时先查第一个单词，点句子里的其他单词换词查。设置里可以关掉「英文单词也查」。
   - 朗读：直接读出来，不显示界面（和电脑版的 Ctrl+Alt+Q 一样）。
2. **悬浮取词**：在 EdgeSpeak 设置里点「打开辅助功能设置」，打开「EdgeSpeak 悬浮取词」。屏幕边上会出现蓝色悬浮按钮（可以拖动）：点它，再点屏幕上的日语或英文单词。
   - 先读界面上的文字（浏览器、大部分 App），文字取自原文；读不到时（游戏、图片、漫画）截屏用 ML Kit 日语 OCR 识别（也认英文，单词之间按位置补上空格），都在手机上完成。
   - 浏览器（Chrome）只告诉整段文字、不告诉点的是哪个字时，用 OCR 认出点中的几个字，再到原文里定位。
   - 第一次 OCR 要加载识别模型，会慢几秒。
3. **AI 解释**：设置里选服务、填密钥（用安卓 Keystore 加密保存）、选模型，可以加备用模型。和电脑版一样，关掉模型的“思考”，有混进来的思考过程会自动去掉。
4. **朗读**用系统的朗读引擎。设置页会检查有没有日语语音；没有的话在系统朗读设置里选「Google 语音服务」并下载日语语音。

## 和电脑版的区别

| | 电脑版 | 安卓版 |
|---|---|---|
| 取词 | Shift 悬停、Ctrl+Alt+Q | 选字菜单、悬浮按钮 |
| 分词 | UniDic 2025-12 | Sudachi 2026-10（Java 版只能读旧格式的词典，新格式出来后需要等 Sudachi 更新） |
| 英汉词典 | ECDICT 完整版 | 日语释义里会出现的词，加上有考试标签、变形或音标的普通英文单词（约 53 万条，够英文取词用；大部分词组和专有名词没收） |
| 朗读 | 微软 Edge 神经网络语音 | 系统朗读引擎 |
| 词典更新 | 每天自动 | 随 App 更新（手机上生成词典太耗电；以后可以做成下载现成的） |
| 繁体转日文新字体 | 有 | 没有 |

## 隐私和上架

- 悬浮取词用的是辅助功能服务：只在你点悬浮按钮之后读取点到的那段文字或截屏，文字只在手机里处理；开了 AI 解释时只把那一句发给你选的 AI 服务。日志里不记录文字内容。
- ML Kit 会向 Google 发送匿名的使用统计（不含识别的文字）。
- 上架 Google Play 时，辅助功能服务要额外说明用途，审核较严；APK 163 MB（加了英文取词用的英汉词典），超过了 Play 对单个 APK 的 150 MB 上限，上架要改用 App Bundle 并把词典放进资源包。现在这个 APK 用调试签名，适合自己安装。

## 从源码构建

需要 JDK 17+（推荐 21）和安卓 SDK（平台 36）。

```bat
rem 1. 用电脑版生成词典（电脑版目录下 python build_dict.py），再整理成安卓版的资源：
python tools\make_assets.py <电脑版的 dict 文件夹> <Sudachi system_core.dic>
rem 2. 打包
gradlew.bat assembleRelease
```

Sudachi 词典从 https://sudachi.s3-ap-northeast-1.amazonaws.com/sudachidict/ 下载 `sudachi-dictionary-<日期>-core.zip`（旧格式；GitHub 上 2026-10 之后的发布是新格式，Java 版读不了）。
